# SAB – עוזר משימות (תוסף Chrome)

תוסף שקורא את המשימה שפתוחה בדפדפן, עונה עליה עם Claude (כולל חיפוש באינטרנט במקורות אמינים) וממלא את התשובות בדף. **הוא אף פעם לא לוחץ "שלח" בשבילך.**

## מה הוא יודע לעשות
- **קורא את כל הדף**: שאלות, סעיפים, שדות טקסט, שאלות אמריקאיות, רשימות, עורכי טקסט, וגם **iframes** (מסגרות פנימיות, גם מאתר אחר).
- **חלון משימה חדש**: כשמשימה נפתחת בחלון נפרד, העוזר מופיע גם בו, ושולח יחד איתו גם את התוכן של החלון שפתח אותו (למשל את הסיפור).
- **בר הסיפור בספרות**: מוצא את הסיפור גם כשהבר בצד סגור. אם לא נמצא, יש בלשונית "סיפור" אפשרות לפתוח את הבר, לבחור אלמנט בדף או להדביק את הסיפור בעצמך.
- **תשובות**: בעברית יומיומית, ברמה של כיתה י"א, בלשון זכר, לכל שאלה ולכל סעיף. בשאלות עובדתיות הוא מחפש באינטרנט ומעדיף מקורות אמינים (gov.il, מט"ח, אוניברסיטאות, אנציקלופדיות), ומציג אותם כקישורים.
- **סיפור ב-PDF או ב-Google Docs**: אם הסיפור מקושר או מוטמע במשימה כקובץ, התוסף מוריד אותו ושולח אותו ל-Claude.
- **בדיקת תשובות חסרות**: אם שאלה לא קיבלה תשובה, מופיעה אזהרה וכפתור **"השלם את החסר"**.
- **עמודים בתוך משימה** (כפתורי 1 2 3 בתחתית): התוסף עובר על כל העמודים, קורא אותם וחוזר לעמוד שהיית בו. במילוי הוא עובר לכל עמוד וממלא בו את התשובות. אפשר לכבות את זה בהגדרות.
- **משימות של כמה עמודים**: הסיפור והתשובות מעמוד 1 נזכרים גם בעמוד 2 ואילך. הסיפור נשמר ב-cache, אז העמודים הבאים זולים יותר.
- **היסטוריה**: כל משימה נשמרת בלשונית "היסטוריה" עם העלות שלה. דף שכבר פתרת מוצג שוב בחינם (ויש כפתור "פתור מחדש").
- **✅ בדוק אותי**: כותבים תשובות לבד ומקבלים ציון לפי מחוון בגרות, מה טוב, מה חסר וגרסה משופרת, וגם כפתור "החלף בגרסה המשופרת".
- **✍️ כתוב כמוני**: מדביקים בהגדרות כמה פסקאות שכתבת, והתשובות נכתבות באותו סגנון.
- **מילוי אוטומטי** + **ביטול מילוי**, כפתור העתקה לכל תשובה, ואפשרות לצרף צילום מסך לשאלות עם תמונה או גרף.

## התקנה ב-Windows (מתעדכן לבד – מומלץ)
1. פותחים **PowerShell**: לוחצים על התחל, כותבים `PowerShell` ולוחצים Enter. לא צריך הרשאות מנהל.
2. מדביקים את הפקודה הזאת ולוחצים Enter:
   ```powershell
   irm https://github.com/ZSWolt/SAB/releases/download/latest/sab-update.ps1 | iex
   ```
   ככה זה עובד גם כש-**Smart App Control** דלוק, כי לא מריצים קובץ שהורד.
3. התוסף יורד לתיקייה `%LOCALAPPDATA%\SAB\extension`, והנתיב שלה מועתק.
4. פעם אחת בלבד ב-Chrome: נכנסים ל-`chrome://extensions`, מדליקים **Developer mode**, לוחצים **Load unpacked** ומדביקים את הנתיב (Ctrl+V).
5. בדף ההגדרות שנפתח מדביקים את **מפתח ה-API של Claude**, משיגים אותו ב-[console.anthropic.com](https://console.anthropic.com/settings/keys).

**מעכשיו הוא מתעדכן לבד:** כל שינוי בקוד נבנה אוטומטית ב-GitHub. משימה מתוזמנת ב-Windows מורידה את הגרסה החדשה בכניסה למחשב וכל שעה, והתוסף טוען את עצמו מחדש. אם דף היה פתוח בזמן העדכון, מרעננים אותו (F5).
- עדכון ידני מיידי: מדביקים שוב את אותה פקודה ב-PowerShell.
- ביטול העדכונים האוטומטיים: `Unregister-ScheduledTask -TaskName 'SAB Extension Updater' -Confirm:$false`
- יומן עדכונים: `%LOCALAPPDATA%\SAB\update.log`


## שימוש
| קיצור | פעולה |
|---|---|
| `Alt+Shift+S` | פתח/סגור את העוזר (גם אחרי שהסתרת את הכפתור) |
| `Alt+Shift+A` | קרא את הדף ופתור |
| `Alt+Shift+F` | מלא את התשובות בדף |

- הכפתור **AI** בצד ימין פותח את הפאנל. ✕ בפאנל סוגר אותו, ו-✕ הקטן על הכפתור מסתיר את הכפתור עד שלוחצים `Alt+Shift+S`.
- אפשר לשנות את הקיצורים ב-`chrome://extensions/shortcuts`.
- **תמיד תעבור על התשובות לפני שאתה שולח.**

## אתרים
יש התאמות לאתרים: Google Forms / Classroom, Moodle, מט"ח (bagruthumanities.cet.ac.il), classe.world ואופק. בכל אתר אחר עובד קורא כללי.
מכיוון שאי אפשר להיכנס לחשבון שלך, ההתאמות לאתרים שדורשים התחברות מבוססות על מבנה כללי. אם משהו לא מזוהה טוב, לוחצים **"ייצא מבנה דף"** בלשונית "משימה" ושולחים את קובץ ה-JSON. הוא מכיל רק את מבנה הדף, בלי התשובות שלך ובלי פרטים אישיים.

## סרטונים (Gemini)
כשיש במשימה סרטון יוטיוב (מוטמע או קישור), **Gemini של Google צופה בו**. הוא רואה את התמונה וגם שומע את הקול, וכותב תיאור מפורט עם זמנים, ציטוטים ותיאור של מה שרואים. את התיאור הזה Claude מקבל כדי לענות על השאלות.
- מפתח בחינם: [aistudio.google.com/apikey](https://aistudio.google.com/apikey). מדביקים אותו בהגדרות תחת "סרטונים".
- רק סרטונים **ציבוריים** עובדים. סרטונים פרטיים או לא רשומים (Unlisted) לא.
- כל סרטון נשמר בזיכרון 30 יום, אז צפייה חוזרת באותו סרטון לא עולה כלום.
- **חינם או בתשלום?** בחינם יש מגבלת בקשות ליום ועד 8 שעות סרטונים ביום, ו-Google יכולה להשתמש במידע לשיפור המוצרים שלה. בתשלום אין מגבלת אורך, המידע לא משמש לאימון, ויש גישה ל-Pro. סרטון של 10 דקות עולה בערך 15–30 אגורות.

## עלות
התשלום הוא לפי שימוש בחשבון Anthropic. אחרי כל פתרון מוצגת עלות משוערת. ב-Opus 5.5 זה בערך כמה סנטים למשימה. Sonnet 5.5 זול יותר וזמין בהגדרות.

## פיתוח
```bash
npm run watch      # בנייה מחדש בכל שינוי
npm run typecheck
npm test           # בדיקות יחידה (vitest + jsdom)
npm run build && npm run e2e   # בדיקה מלאה ב-Chromium עם שרת Claude מדומה
```
